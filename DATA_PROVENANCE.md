# Data provenance and reuse

Only CDC/NCHS Continuous NHANES 2017–2018 DEMO_J, BPX_J, BPQ_J, HIQ_J and HUQ_J are used. The separate 2017–March 2020 prepandemic release is excluded. Source URLs, SHA256, sizes and row counts are in outputs/provenance.json and data/source_manifest.json. HTML codebooks are fetched to `data/raw/` when the analysis runs; they serve as documentation, not executable code.

The code fetches the five source components and their codebooks directly from the official CDC endpoints when they are not already present. This public release intentionally omits cached source files. The published `data/source_manifest.json` records the fingerprints of the previously analyzed CDC file snapshot; any changed upstream content causes the code to stop for review rather than silently yield incomparable estimates. CDC release documentation states publication in February 2020; see each codebook for revisions.

Public-use CDC/NCHS data are released for research subject to NHANES data-use restrictions and appropriate attribution. Do not attempt to identify respondents, link to identified records or infer identities from released variables. See [NHANES data access](https://wwwn.cdc.gov/nchs/nhanes/Default.aspx) and [NCHS data-use restrictions](https://www.cdc.gov/nchs/policy/data-user-agreement.html). Government data reuse does not assign a software license to this repository or third-party packages. Refer to CDC materials rather than assuming every external reference is public domain.

The complete analysis creates participant-level derived data locally in `outputs/design_frame.csv`, but that file is not distributed in this GitHub portfolio. Public-facing `outputs/` contains only aggregate estimates and model diagnostics. All figures and reported numerical estimates originate from the earlier executed source-data analysis; no new results were calculated during repository cleanup. `source_manifest.json` detects changes in source content, but does not replace critical examination of release suitability.
